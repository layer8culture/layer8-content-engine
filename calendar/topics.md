## AI news/tips to share
- GPT-5.6 shipped with the Sol / Terra / Luna tiers and is already selectable in
  Copilot. The builder move: pick the tier by the job (Luna/mini for fast, cheap
  iteration; Sol/Terra for heavier reasoning) instead of defaulting to the biggest.
- Sub-agents / fleet mode are going mainstream: one prompt can fan out to a tester
  agent, a marketing agent, a social agent, and a UX agent running in parallel.
  Frame this as an org chart of agents, not a single super-prompt.
- AI agents are entering real workflows: building websites, drafting SEO/authority
  guides, running multi-hour research. "Works in a demo" still differs from "works
  in a workflow" — show the workflow.
- Model choice is now a skill: multi-model access (OpenAI, Google, Anthropic incl.
  Claude Sonnet 4.6) through one tool means the edge is knowing which model to reach
  for.
- Lightweight AI-built HTML beats heavyweight formats: a ~4KB HTML deck the agent
  generates (and can export to PDF) is a concrete builder tip.
- The content engine itself is the proof point: news becomes posts, prompts become
  visuals, humans still approve the final output.
- AI Tool Drop candidates: GPT-5.6 tiers, Copilot CLI + sub-agents/fleet mode,
  ChatGPT Work mode, and agentic automation tools. Only use them if there is a clear
  builder move the audience can try this week.
