# Layer8Culture — 2026-08-20

Two news beats anchor the day, and they point the same direction. First, the price
floor fell out: OpenAI cut GPT-5.6 Luna roughly 80% to about 20 cents per million
input tokens, Google and Anthropic followed, and August alone produced around 19
model releases across 16 providers. Second, GitHub stopped treating agents like a
feature — Agent HQ is live and Agent Plugins 1.0 shipped for VS Code, the Copilot
CLI, and the Copilot app, while the coding agent now takes an issue, works in a
sandbox, and hands back a draft pull request.

Underneath both: OpenAI's unreleased Astra model published machine-checkable proofs
for ten long-open math problems, one of them open since 1999, at roughly $200 of
compute each. Not "trust us" — Lean 4, in a public repo, compile it yourself.

That pairs with the Tech Thursday ladder we drew live: model, chat, workflow, build.
Most people stop at the chat and call the workflow layer an agent. It isn't. It's a
loop. That distinction runs through the batch as the day's spine — and it's Thursday,
so the story hands it to the live show.

The close is the culture read. Stripe is acquiring OpenRouter. The models get cheap
while the layer underneath them gets bought. Which layer do you own?
