# Layer8Culture — 2026-08-18

Two real things landed this week, and they point in the same direction: the price of
running AI collapsed (GPT-5.6 Luna at $0.20 per million input tokens, ~80% down), and
Claude Opus 5 turned "thinking" into a five-level effort dial instead of an on/off
switch. Both stories say the same thing to a builder — the tool stopped being the
constraint. What's left is intent.

That pairs with the latest Tech Thursday, where the workflow itself was the story:
sub-agents with jobs (tester, copy, design, marketing), each able to run a different
model, reviewing the plan before a human ever sees it — and the math app built for a
fifth grader that gives clues instead of answers and rebuilds its question bank weekly
around the problems he actually missed. The user becoming the builder, shown rather
than claimed.

The day is built around that: a hard news open, a tactical tool drop, the workflow
framework, the personal build at prime time, and a culture close.
