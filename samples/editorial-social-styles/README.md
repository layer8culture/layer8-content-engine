# Layer8Culture social typography samples

These files are review-only samples for the new Layer8Culture social typography system.
They are outside `queue/`, so they do not schedule or publish content.

## What to review

- `brand-title-card.png`: calmer brand title-card layout using Bebas Neue headlines.
- `editorial-drop.png`: bolder Editorial Drop layout for product/news/mixed media moments.
- `mixed-carousel-video-slide-1.mp4`: square mixed-carousel video slide sample.
- `mixed-carousel-video-slide-1-cover.png`: preview cover for the mixed-carousel video slide.
- `reel-bebas-overlay.mp4`: vertical reel sample using Bebas Neue overlay text.
- `reel-bebas-overlay-cover.png`: cover frame sampled after the first reel text beat appears.

## High quality end-to-end sample

The `hq-end-to-end/` folder contains a full non-publishing sample generated through
the engine:

- `hq-style-reel-sample.mp4`: Sora-generated vertical reel with Bebas Neue overlay beats.
- `hq-style-reel-sample-cover.png`: reel cover frame with the first overlay beat.
- `hq-style-carousel-sample-1.mp4`: square mixed-carousel video slide.
- `hq-style-carousel-sample-1-cover.png`: square video-slide cover.
- `hq-style-carousel-sample-1.png` through `hq-style-carousel-sample-4.png`: carousel slides.
- `hq-sample-queue.output.json`: sample queue metadata used for generation. It is outside
  `queue/` and will not publish.

## Brand rule being tested

Layer8Culture social content should use bold Bebas Neue condensed headlines across a
mix of brand title-card and Editorial Drop layouts. Typography accents use Electric Blue.
Sora and image generation stay text-free. The renderer composites readable text after
generation.
